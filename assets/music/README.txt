音乐文件目录

请将 MP3 音乐文件放到此目录下，然后在 js/config.js 中修改 playlist 数组。

示例：
  1. 把 canon.mp3 放到这个目录
  2. 在 config.js 中修改：
     playlist: [
       { name: '卡农', src: 'assets/music/canon.mp3' },
       { name: 'River', src: 'assets/music/river.mp3' },
       { name: '婚礼', src: 'assets/music/wedding.mp3' },
     ];
